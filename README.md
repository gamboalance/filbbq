# filbbq
This is the GitHub repository for [Robust Bias Evaluation with FilBBQ: A Filipino Bias Benchmark for Question-Answering Language Models](https://arxiv.org/abs/2602.14466)--which has been accepted for publication in the The Fifteenth Language Resources and Evaluation Conference (LREC 2025). We release this dataset under a Creative Commons Attribution-ShareAlike 4.0 International License.
